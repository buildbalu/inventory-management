InventoryPro — System Architecture

Factory Inventory Management System  ·  Vue 3 + FastAPI + In-Memory JSON

Tech Stack

Frontend

Vue 3 Composition API served by Vite dev server on port 3000.

Vue 3 Vite Axios

Backend

Python FastAPI with Uvicorn on port 8001. Pydantic models for request/response validation.

FastAPI Uvicorn Pydantic

Data Layer

No database. JSON files loaded into memory at startup and filtered at runtime via Python list comprehensions.

JSON Files In-Memory

Extras

Internationalization (EN / JA), Vue Router for SPA navigation, localStorage for locale persistence.

i18n Vue Router localStorage

Frontend Structure

Views (Pages)

  • Dashboard — KPI cards, donut chart, revenue trends
  • Inventory — Stock table, search, status badges
  • Orders — Order tracking, expandable items
  • Spending — Revenue vs costs, category breakdown
  • Demand — Forecasts with trend indicators
  • Reports — Quarterly & monthly analytics

  • useFilters — Singleton filter state; getCurrentFilters() maps UI refs to API params

Components & Modals

  • FilterBar — 4 global filter dropdowns + Reset
  • ProfileMenu — Avatar dropdown

Key Patterns

Frontend — Composable Singleton

useFilters.js declares refs outside the exported function, making filter state a true singleton shared across all components. Every view reads from the same reactive refs — no prop drilling or Vuex required.

Backend — In-Memory Filtering

mock_data.py loads all JSON at startup into module-level variables. main.py filters with Python list comprehensions inside each endpoint handler. Restarting the server resets any runtime mutations (e.g. created purchase orders).

Reactivity Chain

FilterBar updates a ref → view's watch() fires → loadData() called → Axios request built → response assigned to ref → computed properties recalculate → v-for re-renders. Raw data always stored in refs; derived views always in computed.

i18n & Currency

useI18n resolves dot-path keys (e.g. 'dashboard.title') against locale objects loaded from /locales/en.js and /locales/ja.js. Locale is persisted in localStorage. Currency auto-switches: USD for English, JPY for Japanese.
